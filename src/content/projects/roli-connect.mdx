<ProjectDescription>
    ROLI Connect is a desktop taskbar application that allows a user to
    authenticate, and then browse and install the software that they own
    licenses to. It also features a number of other functions, such as
    installing soundpacks for ROLI's various synths, learning about their
    hardware products, and registering ROLI hardware to their account.

    The app also installed the ROLI Hardware Driver, which makes it easier for ROLI software to communicate with ROLI hardware and vice versa.

    On this project I was primarily responsible for implementing the UI and associated animations.

</ProjectDescription>
